# Design & UX Rules

1. **NO SPARKLES ICONS**: Never use Sparkles (`Sparkles` from lucide-react) anywhere in user interfaces or projects.
2. **NO GENERIC / ARTIFICIAL AI DESIGNS**: Base all UI designs on established Dribbble, Linear, Vercel, Stripe, and ADPList design patterns. Prioritize typography, subtle micro-interactions, clean whitespace, and brand colors.
